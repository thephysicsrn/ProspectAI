# ⚡ ProspectAI — Inteligência de Prospecção B2B & Captação com IA

Plataforma SaaS moderna e de alta performance desenvolvida para acelerar a prospecção B2B de times comerciais, SDRs e closers corporativos. O sistema indexa mais de **32.000 empresas e MEIs** em todo o Brasil (com forte densidade no Nordeste), integrando dados cadastrais da **Receita Federal**, contratos vigentes do **PNCP**, estimativas do **eSocial** e geração de propostas com Inteligência Artificial.

---

## 🚀 Principais Recursos

- **🔍 Busca B2B & Filtros Multicritério:**
  - Filtragem instantânea por Estado (UF), Município, CNAE (Setor), Faixa de Faturamento e Porte (MEI, ME, EPP, Médio e Grande).
  - Identificação de empresas com contratos públicos ativos e capacidade financeira comprovada.
  
- **📊 Dossiê 360 & Inteligência Estratégica:**
  - Visualização de Quadro Societário (QSA) com nomes dos sócios/administradores.
  - Indicadores fiscais declarados: CND Federal, FGTS, Débitos Trabalhistas e enquadramento tributário (SIMEI, Simples Nacional, Lucro Presumido).
  - Estimativa de colaboradores e folha salarial via eSocial.

- **📞 Captação em 1 Clique (WhatsApp & Contatos):**
  - Botão de contato direto com abertura imediata do WhatsApp (`https://wa.me/55...`) e pitch personalizado preenchido com o nome do sócio e da empresa.
  - Links diretos para E-mail corporativo e localização no Google Maps.

- **🧮 Dimensionamento de Ticket & Capacidade Financeira:**
  - Cálculo algorítmico de faixas recomendadas de ticket mensal e contratos anuais baseado no faturamento presumido e porte.

- **📝 Gerador de Propostas Comerciais com IA:**
  - Criação de minutas comerciais e pitches de venda personalizados em segundos, prontos para exportação ou impressão em PDF.

- **💼 Pipeline de Prospecção & Listas Salvas:**
  - Gestão de leads qualificados por estágios do funil: *Novo*, *Qualificado*, *Em Contato*, *Proposta Enviada* e *Convertido*.

## 🛠️ Stack Tecnológica

- **Frontend / Framework:** [Next.js 14](https://nextjs.org/) (App Router, Server Components & Client Components)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/) com paleta dark high-tech (Indigo & Cyan)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Armazenamento & Indexação:** In-Memory Indexed Maps com resposta $O(1)$ para mais de 32.000 registros e integração com BrasilAPI / Receita Federal.

## 📦 Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/thephysicsrn/ProspectAI.git
   cd ProspectAI
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   - Aplicação Interna: [http://localhost:3000](http://localhost:3000)
   - Landing Page Institucional: [http://localhost:3000/landing](http://localhost:3000/landing)
   - Login Corporativo: [http://localhost:3000/login](http://localhost:3000/login)
